# ModSync v0.2.0 发布说明 (Release Notes)

这是 ModSync 的首个正式可开源版本。

---

## 核心特性

1. **轻量单容器发布端 (Server)**：
   - 内置响应式中文管理后台，适配桌面与移动端。
   - 全文 SHA-256 哈希比对新增、修改、删除模组，严格忽略临时与无关文件。
   - 具备发布时变动核对、空目录防护、只读 Token 鉴权与服务一键启停。
2. **多版本客户端模组支持 (Client Mod)**：
   - **Forge 1.20.1**：实测兼容经典 1.20.1 Forge 模组生态。
   - **NeoForge 26.1.2**：实测兼容新一代 NeoForge 架构。
   - 纯手动更新体验：零启动联网、零自动弹窗、零后台轮询。
   - 自装模组严格保留，修复模式安全对齐基准，更新器本体绝对受保护。
3. **后台一键生成更新器**：
   - 选定目标版本和访问地址，由服务端内存流式注入配置生成 JAR，无需在生产机运行 Gradle。
4. **Linux 一键自动化部署**：
   - 提供 `install.sh` 脚本，自动检查环境、生成安全凭据并启动容器。
   - 支持宿主机分发根目录映射与子目录动态切换，避免路径逃逸。
